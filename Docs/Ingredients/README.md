# 시끄러운 포션공방 재료 에셋

씬 2(창고 재료 탐색)에서 쓰는 재료 18개의 3D 모델, 텍스처, 책자용 썸네일과 데이터 문서다.

## 폴더

| 폴더 | 내용 |
| --- | --- |
| `Assets/Arts/Models/Ingredients/Models/` | 재료 모델 18개. `ING_A1.fbx` ~ `ING_F3.fbx` |
| `Assets/Arts/Models/Ingredients/Textures/` | 모델별 베이스 컬러 텍스처. `ING_A1_tex.png` 등 |
| `Docs/Ingredients/Thumbnails_Light/` | 책자용 썸네일, 밝은 배경. `ING_A1.png` 등 (1024×1024) |
| `Docs/Ingredients/Thumbnails_Dark/` | 책자용 썸네일, 어두운 배경 |
| `Docs/Ingredients/MVP_Data.md` | MVP 데이터 문서 내보내기 (질병, 포션, 재료, 인물, 판정 규칙, 대사) |

## 모델 규격

- 높이 약 0.5m, 피벗은 바닥 가운데. 달걀형 알 2개(E2, E3)는 0.45m, 깃털 C2·C3은 끝을 잘라 0.49m 안팎이다.
- 폴리곤은 모델당 약 2만(삼각형). C1은 약 8천, B3는 약 1만 4천이다.
- 텍스처는 베이스 컬러 한 장이다(PBR 맵 없음). 무광 재질로 쓰면 된다.
- FBX에 텍스처가 들어 있다. Unity에서 머티리얼이 비어 보이면 `Textures/` 폴더의 같은 이름 PNG를 베이스 맵에 연결한다.
- 파일 이름은 재료 ID와 같다. 코드는 ID(A1~F3)로 재료를 찾는다.

## 재료 목록

같은 계열의 재료 3개는 계열 특징 a·b·c 중 2개씩만 가진다. 구별 포인트는 그 재료에만 빠진 특징이다.

| ID | 이름 | 가진 특징 | 구별 포인트 |
| --- | --- | --- | --- |
| A1 | 별밤버섯 | 파란 줄기, 흰 점 | 갓이 둥글다 |
| A2 | 싸락버섯 | 흰 점, 뾰족한 갓 | 줄기가 희다 |
| A3 | 마법사버섯 | 뾰족한 갓, 파란 줄기 | 흰 점 없음 |
| B1 | 멍뿌리 | 보랏빛 껍질, 단면 나이테 | 혹 없음 |
| B2 | 마녀뿌리 | 단면 나이테, 혹 | 껍질이 흙빛 |
| B3 | 두꺼비뿌리 | 혹, 보랏빛 껍질 | 단면 나이테 없음 |
| C1 | 먹붓깃 | 까만 끝, 가로 줄무늬 | 끝이 갈라지지 않음 |
| C2 | 리본깃 | 가로 줄무늬, 갈라진 끝 | 끝이 까맣지 않음 |
| C3 | 그을음깃 | 갈라진 끝, 까만 끝 | 줄무늬 없음 |
| D1 | 새벽수정 | 두 가지 색, 돌에 붙음 | 끝이 뾰족함 |
| D2 | 얼음수정 | 돌에 붙음, 뭉툭한 끝 | 한 가지 색 |
| D3 | 노을수정 | 뭉툭한 끝, 두 가지 색 | 돌 없이 보석만 |
| E1 | 쿠키알 | 갈색 껍질, 반점 | 둥글다 |
| E2 | 주근깨알 | 반점, 길쭉함 | 껍질이 희다 |
| E3 | 도토리알 | 길쭉함, 갈색 껍질 | 반점 없음 |
| F1 | 파도소라 | 주황 안쪽, 물결무늬 | 가시 없음 |
| F2 | 왕관소라 | 물결무늬, 가시 | 안쪽이 희다 |
| F3 | 횃불소라 | 가시, 주황 안쪽 | 물결무늬 없음 |

## 알아 둘 점

- **멍뿌리(B1):** 껍질이 위는 보라색, 아래는 주황색으로 번져 있다. 보랏빛으로 통일하려면 텍스처 수정이 필요하다.
- **수정(D):** 텍스처가 불투명하다. 반투명으로 보이게 하려면 Unity에서 머티리얼을 바꾼다.
- **새벽수정(D1)과 노을수정(D3):** 둘 다 보라와 청록이라 색 조합이 같다. 구분은 돌 유무와 끝 모양으로 한다.
- **재료 이름:** 제조법 종이에만 나오고 게임 화면에는 표시하지 않는다.

## 제작 방법

- 형태와 텍스처는 Meshy로 생성했다(텍스트 기반, 소라 3개는 참고 그림 기반).
- 알의 형태, 깃털의 갈라진 끝, 두꺼비뿌리의 단면, 마녀뿌리의 혹, 버섯 갓과 기둥, 노을수정의 끝은 Blender 스크립트로 손봤다.
- 알 3개의 텍스처는 스크립트로 새로 그렸다.
- 썸네일은 Blender로 렌더링했다.

데이터의 기준은 MVP 데이터 문서다. `Docs/Ingredients/MVP_Data.md`는 2026-11-19에 내보낸 사본이다.

## Unity 메타 파일

`.meta` 파일은 넣지 않았다. Unity에서 프로젝트를 열면 자동으로 만들어지니, 그때 생긴 `.meta`를 함께 커밋한다.
