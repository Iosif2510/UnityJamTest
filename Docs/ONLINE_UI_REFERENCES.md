# 온라인 화면 레퍼런스 조사

2026-11-22. 온라인 협동 화면(방 만들기, 표지와 역할 선택, 위층 공방)이 기존 화면과 따로 논다는 지적을 받고, 참고 게임의 실제 스크린샷을 Steam 상점에서 확인해 정리했다. 스크린샷은 각 게임 상점 페이지의 공식 이미지이고, 내부 참고용 링크만 적는다. 게임에는 쓰지 않는다.

Papers, Please와 Cultist Simulator는 이미지를 불러오지 못해 이번 조사에서 직접 확인하지 못했다.

## 1. 갈바테인: 모험가 길드 사무소 (GDD의 주 레퍼런스)

- [접수 창구 화면 1](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/3208930/7216e343cfcd6b143696885f061c28651ea4d948/ss_7216e343cfcd6b143696885f061c28651ea4d948.1920x1080.jpg)
- [접수 창구 화면 2](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/3208930/0279fb04fb84e0664825dd1cb4b55e0db4769d1c/ss_0279fb04fb84e0664825dd1cb4b55e0db4769d1c.1920x1080.jpg)
- [주점 화면](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/3208930/b894d8f7586da4b5f52fff254f3f9e3b0cc6ce88/ss_b894d8f7586da4b5f52fff254f3f9e3b0cc6ce88.1920x1080.jpg)

화면에서 본 것:

- 3열 격자다. 가운데가 장면 창(큰 인물, 말풍선), 왼쪽이 문서(의뢰서 양피지와 도감), 오른쪽이 신분증 카드, 체크리스트, 지도다. 패널 사이 간격이 모두 같고 위아래 줄이 맞는다.
- 재질은 둘뿐이다. 짙은 남색 패널과 크림색 양피지. 강조는 금색 알약 모양 라벨 하나로 한다.
- 가운데 창 위에 머리띠가 있다. 위치 아이콘, 화면 이름, 날짜, 숫자 두 개가 한 줄에 놓인다.
- 문서 패널에는 제목(양옆에 ✦ 장식), 점선, 본문, 아래쪽 날짜가 있다. 중요한 구절에는 밑줄이 쳐져 있다.
- 체크리스트는 ◆ 표시와 취소선으로 진행을 보여 준다.
- 배경은 흐리게 처리한 방 그림이고, 정보는 전부 패널 안에 있다.

우리에게 주는 뜻: 이 게임에서 문서를 보는 사람의 화면은 "책상 위에 흩어진 종이"가 아니라 "줄 맞춘 패널"이다. 옆 패널이 있는 것 자체는 문제가 아니었고, 패널이 격자·머리띠·장식 없이 떠 있던 것이 문제였다.

## 2. Strange Horticulture

- [작업대 화면](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1574580/ss_bdf4e7e6ab970f19c95ae96896e9457a95dbdf65.1920x1080.jpg)
- [지도 화면](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1574580/ss_741db5d7020d737ea8aba278e95f7111d7ca8f6e.1920x1080.jpg)

- 화면이 나무 틀로 구역이 나뉜다. 위는 선반, 가운데는 펼친 책이 놓인 작업대, 오른쪽은 손님과 서랍이다.
- 문서는 책상에 흩어 놓지 않고 이름표가 붙은 서랍 칸(Items, Clues, Letters, Labels)에 정리돼 있다.
- 도구는 왼쪽에 황동 테두리의 둥근 버튼으로 세로로 줄지어 있다.
- 자세히 볼 때는 화면을 덮지 않고 둥근 창과 집게 달린 메모가 작업대 위에 뜬다.
- 앞쪽 모서리에 잎이 겹쳐 있어 화면에 깊이가 생긴다.

## 3. Potion Craft

- [제조 화면](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1210320/ss_a5197ad5bb35e9899c9e751820cdb9dbc0ceb308.1920x1080.jpg)
- [연금술 장치 화면](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1210320/ss_a0c1d496af8071557b72dae3dc3f7c01aa9d9c0a.1920x1080.jpg)

- 화면 전체에 무늬 테두리가 둘러져 있고, 오른쪽 열(재고와 할 일 목록)은 어느 화면에서나 같은 자리에 같은 모양으로 있다.
- 가운데에는 걸어 놓은 두루마리가 있고, 도구는 아래 선반에 서 있다.
- 선의 굵기, 색 수, 글꼴이 화면 전체에서 하나다.

## 4. 포셔노믹스

- [가게 화면](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1874490/ss_b20e65b00d6be8b1cdf7b22732410ff8fc279ccd.1920x1080.jpg)
- [흥정 화면](https://shared.akamai.steamstatic.com/store_item_assets/steam/apps/1874490/ss_339bea90d419d56460d11343576be82b01a652c9.1920x1080.jpg)

- 표시 하나하나가 모양을 가진 배지다. 남은 인내심은 모래시계 그림이 든 육각 배지와 큰 숫자, 이름은 알약 모양 판, 돈은 계기판 모양이다.
- 숫자와 글자만 떠 있는 표시는 없다.

## 5. 우리 게임의 기존 화면

- 접객: 왼쪽 양피지 대사창과 붉은 이름표, 가운데 큰 손님, 위 가운데 남은 시간.
- 창고: 위 가운데에 모래시계 그림이 달린 시간 막대(`Timer_Hourglass`, `Timer_Frame`, `Timer_Fill`), 아래 가운데에 주머니 세 칸.
- 결과: 양피지 카드, 도장 그림(`훌륭한`, `그럭저럭`, `stamp-slow`, `stamp-communication`), 노란 나무 버튼.

## 6. 내가 만든 화면에 없던 것

| 기준 | 참고 게임과 기존 화면 | 내가 만든 화면 |
| --- | --- | --- |
| 격자 | 패널의 가장자리와 간격이 맞음 | 종이 8장을 2×4로 늘어놓고 나머지는 빈자리에 끼워 넣음 |
| 주인공 | 화면마다 가장 큰 것이 하나 있음(인물, 펼친 책, 두루마리) | 여덟 장이 같은 크기라 눈 둘 곳이 없음 |
| 머리띠 | 화면 이름과 핵심 숫자가 위쪽 한 줄에 있음 | 없음. 시간이 구석의 숫자 |
| 배지 | 시간·점수가 그림과 틀을 가짐 | 글자만 있음 |
| 문서 꾸밈 | 제목 장식, 점선, 날짜, 밑줄 | 민무늬 사각형에 글자 |
| 기존 자산 | — | 창고의 모래시계 막대, 결과 도장, 붉은 이름표를 하나도 쓰지 않음 |
