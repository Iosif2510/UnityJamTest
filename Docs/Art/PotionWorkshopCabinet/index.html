노말맵은 2D 실루엣 높이에서 만든 면 단위 보조 맵입니다. 3D 메시에서 베이크한 맵은 아닙니다. 색 이미지에는 약한 기본 명암이 포함되어 있습니다.
PNG와 노말맵은 같은 크기입니다. 배치는 layout.json의 좌표를 사용하며, 실행 중 비율이나 크기를 바꾸지 않습니다. 맞춤 검사 결과 · 파일 안내
