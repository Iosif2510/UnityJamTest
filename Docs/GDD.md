## 개요

한 판은 손님 한 명을 3분 안에 진단하고, 재료를 모아 끓이고, 알맞게 포장해 건네는 것이다.

**핵심 규칙:** 두 플레이어는 상대의 정보를 직접 볼 수 없고, 말로만 설명한다. 단계마다 주로 말하는 쪽이 바뀐다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 비대칭 정보 2인 협동 (오프라인, 같은 자리) |
| 제조자 | PC 앞에 앉아 게임을 조작한다. 손님, 창고, 솥, 포장대를 본다 |

## 팀 구성과 문서 사용법

이 문서는 작업의 기틀이다. 각 씬 섹션은 **레퍼런스 → 구성 요소 → 작업 가이드 → 조정 값 → 미확정** 순서로 읽는다.

| 역할 | 담당 범위 | 주요 산출물 |
| --- | --- | --- |
| 기획 | 문서, 데이터 값, 종이 자료, 대사 | MVP 데이터 표, 해설자 메모 7장 |
| 프로그래머 (시니어) | 전체 구조, 씬 흐름, 판정, 1인칭 조작 | Unity 프로젝트, 데이터 구조, 빌드 |
| 아티스트 A (2D) | 씬0·씬1·씬3·결과 화면, 손님 초상화, UI | 2D 스프라이트, UI 에셋 |
| 아티스트 B (3D) | 씬2의 오브젝트 전부(재료 제외): 창고 공간, 선반, 솥, 소품 | 3D 환경 모델, 머티리얼, VFX |
| 아티스트 C (기획 겸임) | 재료 3D 모델 18개, 책자용 썸네일, 해설자 종이 | 재료 FBX와 텍스처, 썸네일, 인쇄용 PDF |

- **확정:** 바로 작업한다.
- **조정 값:** 코드에 박지 않고 데이터 파일로 빼서 기획이 바꿀 수 있게 한다. 적힌 값은 초안이다.
- **미확정:** MVP 테스트 후 정한다. 작업은 기본값으로 먼저 진행한다.

### 공통 규칙

- 화면 기준 1920×1080(16:9), Unity 6 + URP. 시연 기기는 노트북이다.
- 파일 이름 규칙: 재료는 ING_<계열><번호>(예: ING_A1), 초상화는 POR_<인물 ID>_<레이어>(예: POR_ELF_F1_BASE)다.
- **2D 아트 방향(씬0·1·3):** 갈바테인처럼 캐릭터를 크게, 대사창을 또렷하게, 따뜻한 나무톤 공방.
- **3D 아트 방향(씬2):** PEAK·Overcooked처럼 밝고 따뜻한 채도와 단순한 형태. 구도는 참고하지 않는다.
- **데이터의 기준은 MVP 데이터 문서다.** 이 문서와 다르면 MVP 데이터가 맞다.

## 씬0 · 대기

씬0은 별도 씬이 아니라 씬1 화면 위에 커튼이 닫힌 상태다. 다음 팀이 앉기 전 부스에 띄워 두는 대기 화면이다.

- 화면: 접객 창구 앞에 커튼이 닫혀 있고, 가운데에 **손님 받기** 버튼이 있다.
- 버튼을 누르면 커튼이 걷히고, 잠시 뒤 손님이 들어오며 씬1이 시작된다.
- 제한 시간은 손님이 들어온 순간부터 잰다(초안).
- 결과 팝업을 닫으면 이 화면으로 돌아온다. 다음 팀이 아무 설명 없이 버튼만 눌러 시작할 수 있어야 한다.
- 선택: 커튼에 "제조자는 화면 앞에, 해설자는 메모 앞에" 같은 한 줄 안내를 넣으면 스태프 설명이 줄어든다.

## 씬1 · 접객(진단)

제조자가 손님의 긴 수다에서 증상만 골라 전하고, 해설자는 메모 6장 가운데 증상이 맞는 장을 찾는다. 목표 시간은 15~20초다.

### 제조자 화면 (Ref. 갈바테인: 모험가 길드 사무소)

- **구성:** 손님 초상화, 긴 대사창, 남은 시간 표시.
- **대사:** 잡담과 증상이 섞인 200자 안팎의 문단이 어절 단위로 출력된다. 손님 한 명당 LLM을 한 번 호출해 만들고, 실패하면 MVP 데이터의 대체 대사를 쓴다.
- **텍스트 이펙트:** 증상 구간(sym 태그)에만 글자 효과를 준다. 효과는 질병마다 다르다. 예: 그림자 늑장증은 글자 그림자가 늦게 따라붙고, 되울림증은 말끝 두 글자가 흐리게 한 번 더 나온다.
- **폰트:** 대사창은 메이플스토리. 본문 Light, 이름표와 증상 구간 Bold.
- **다음 씬으로:** 대사가 끝나면 **창고로** 버튼이 나타나고, 제조자가 누르면 씬2로 전환한다. 해설자가 맞는 메모를 찾을 때까지 기다렸다 누르는 것이 자연스럽다.

### 해설자 자료 · 약물공정 안내표 (메모)

- 질병 문서를 따로 두지 않는다. 약 하나에 메모 한 장, 모두 6장이다. 약방 주인이 손님 말을 받아 적고 재료를 메모한 종이처럼 만들었다.
- 메모 위쪽에 그 병에 걸린 손님들이 하는 말 여덟 줄이 있다. 게임에 나오는 증상 세 가지, 게임에 없는 증상 두 가지, 진단과 무관한 말 세 가지가 섞여 있다.
- 해설자는 제조자가 전한 증상으로 맞는 장을 찾고, 그 장에서 바로 재료 설명으로 넘어간다.
- 질병은 6개이고 쌍둥이 질병은 없다.

| ID | 질병 | 대표 증상 | 치료 포션 |
| --- | --- | --- | --- |
| DIS_01 | 그림자 늑장증 | 그림자가 늦게 따라옴, 해 질 녘에 심해짐, 돌아보면 그림자가 없음 | 그림자 재촉약 |
| DIS_02 | 되울림증 | 한 말의 끝이 다시 들림, 조용한 곳에서 심해짐, 혼잣말도 되돌아옴 | 말끝 매듭약 |
| DIS_03 | 들뜸앓이 | 몸이 가벼워짐, 발이 땅에 닿지 않음, 바람이 불면 심해짐 | 발붙임약 |
| DIS_04 | 거울잠 | 거울 속 내가 졸음, 정작 나는 밤에 잠을 못 잠, 거울 속 내가 혼자 하품함 | 거울 깨움약 |
| DIS_05 | 빗물혀 | 무엇을 먹어도 빗물 맛, 비 오기 전날 혀가 저림, 입 안에서 흙냄새 | 입맛 개는 약 |
| DIS_06 | 서리손 | 손끝이 늘 차가움, 닿는 물건이 얼어붙음, 아침에 더 심해짐 | 손끝 녹임약 |

## 씬2 · 재료 탐색

제조자는 1인칭으로 창고를 돌며, 해설자의 설명만 듣고 재료 3개를 찾아 솥에 넣는다. 목표 시간은 60초다.

### 제조자 조작 (Ref. PEAK)

| 입력 | 동작 |
| --- | --- |
| 마우스 | 시점 회전 |
| WASD | 이동 |
| 좌클릭 | 선반의 재료 집기. 집으면 화면 가까이 들어 자세히 볼 수 있다 |
| F | 들고 있는 재료를 주머니에 넣기 |
| 우클릭 | 들고 있는 재료를 내려놓기. 잘못 집었을 때 쓴다 |
| 좌클릭 (솥) | 솥 상호작용 시작 |

- **인터랙션 프롬프트:** 바라보는 대상마다 "[클릭] 집기", "[F] 주머니에 넣기", "[클릭] 솥에 넣기"를 띄운다.
- **주머니 UI:** 화면 아래 칸 3개에 넣은 재료 아이콘을 보여 준다.
- **경로선:** 주머니에 재료 3개를 넣으면 바닥에 솥까지 빛나는 선이 나타난다. NavMesh 경로를 LineRenderer로 그리는 방식을 권장한다. 개수 기준으로 띄운다. 정답 여부로 띄우면 정답을 알려 주게 된다.
- **창고:** 방 하나에 선반 여러 개, 재료 18개를 항상 모두 진열한다. 매 판 재료 위치를 섞어 외워서 푸는 것을 막는다.

### 해설자 자료 · 메모의 재료 부분

- 씬1에서 찾은 메모의 아래쪽에 재료 3개가 있다. 재료마다 작은 낙서 그림과 화살표 메모 6~7개가 붙어 있다.
- 그 가운데 창고에서 재료를 가려내는 데 쓰이는 메모는 2개뿐이다. 나머지는 맞는 말이지만 구별에는 도움이 안 되거나, 눈으로 확인할 수 없는 말이다. 어느 것이 쓸모 있는지는 종이에 표시하지 않는다.
- 재료 이름은 메모에만 있고 게임 화면에는 표시하지 않는다.

### 재료 계열 설계

재료는 6계열(버섯, 뿌리, 깃털, 수정, 알, 소라)에 3개씩, 모두 18개다. 같은 계열의 세 재료는 서로 닮았고, 포션마다 계열이 다른 재료 3개를 쓴다.

- 계열마다 특징 a·b·c를 정한다. 1번 재료는 a와 b, 2번은 b와 c, 3번은 c와 a를 가진다. 특징 하나만 들어서는 고를 수 없고, 두 개를 들어야 하나로 좁혀진다.
- 포션 6개가 재료 18개를 한 번씩 쓴다. 포션마다 1번, 2번, 3번 재료가 하나씩 들어간다.
- 재료별 특징과 포션별 재료의 전체 표는 MVP 데이터 문서에 있다.

| 계열 | 특징 a | 특징 b | 특징 c | 재료 (1번, 2번, 3번) |
| --- | --- | --- | --- | --- |
| A 버섯 | 줄기가 파랗다 | 갓에 흰 점이 있다 | 갓 끝이 뾰족하다 | 별밤버섯, 싸락버섯, 마법사버섯 |
| B 뿌리 | 껍질이 보랏빛이다 | 잘린 단면에 나이테가 있다 | 몸에 혹이 돋아 있다 | 멍뿌리, 마녀뿌리, 두꺼비뿌리 |
| C 깃털 | 끝이 까맣다 | 가로 줄무늬가 있다 | 끝이 두 갈래로 갈라졌다 | 먹붓깃, 리본깃, 그을음깃 |
| D 수정 | 두 가지 색이 섞여 있다 | 돌에 붙어 있다 | 기둥 끝이 뭉툭하다 | 새벽수정, 얼음수정, 노을수정 |
| E 알 | 껍질이 갈색이다 | 반점이 있다 | 길쭉하다 | 쿠키알, 주근깨알, 도토리알 |
| F 소라 | 입구 안쪽이 주황색이다 | 갈색 물결무늬가 있다 | 가시가 돋아 있다 | 파도소라, 왕관소라, 횃불소라 |

- **난이도 조절:** 메모에서 재료 하나에 붙는 메모 수(지금 6~7개)를 줄이면 쉬워진다. MVP 테스트로 정한다.

### 솥 투입과 전환

1. 솥과 상호작용하면 주머니의 재료가 자동으로 솥에 들어간다.
2. 플로팅 텍스트로 해설자에게 지시한다. 예: "해설자님, 접객 매뉴얼로 바꿔 주세요!"
3. 약 4초 뒤 씬3으로 전환한다.
4. 넣은 재료와 레시피를 비교한 결과(틀린 개수)를 저장해 엔딩에서 쓴다.

## 씬3 · 처방(포장)

제조자는 2D 화면에서 손님에게 맞는 병 1개와 잉크 1개를 고른다. 병은 성별, 잉크는 외모 조건 퍼즐로 정해진다. 목표 시간은 20초다.

### 제조자 화면

- 씬1과 같은 2D 접객 화면이다. 손님 초상화와 작업대가 보인다.
- 작업대: 병 3종(네모, 하트, 동그라미)과 잉크병 6개.
- 잉크병에는 번호 대신 그림을 그린다: 잎, 별, 불, 송곳니, 돌멩이, 빈 동그라미. 해설자의 종이에 같은 그림이 낙서로 있다.
- 병과 잉크를 고르고 **건네기**를 누르면 엔딩으로 간다.

### 병 규칙

| 손님 | 병 |
| --- | --- |
| 남성 | 네모 |
| 여성 | 하트 |
| 성별이 없는 종족 | 동그라미 |

성별은 초상화 외형으로 분명히 구분되게 그린다. 골렘은 성별이 없어 동그라미 병이다.

### 잉크 판정 규칙

판정은 아래 우선순위 규칙으로 한다. 이 표는 코드와 Validator용이며, 해설자의 종이에는 이 순서를 그대로 적지 않는다(아래 '접객 매뉴얼' 참고).

1. **우선순위:** 위에서부터 차례로 확인하고, 처음 맞는 규칙 하나만 적용한다. 조건이 겹쳐도 답이 하나로 정해진다.
2. **조건은 규칙당 1~2개:** 3개 이상은 말로 주고받기 어렵다.
3. **예외 규칙 하나:** "단, ~이면 건너뛴다"를 하나 섞어 함정을 만든다.
4. **기본값:** 마지막 규칙은 "아무것도 해당하지 않으면"으로 두어 모든 손님에게 답이 있게 한다.
5. **난이도 = 질문 수:** 해설자가 제조자에게 몇 번 물어야 답이 나오는지로 조절한다.
6. **부르기 쉬운 값만:** 빨강, 검정, 파랑 같은 기본색만 쓴다. 청록, 자주처럼 사람마다 다르게 부르는 색은 피한다.
7. **데이터 검증:** 손님 조합 전체에 규칙을 돌려 답이 정확히 하나 나오는지 스크립트로 확인한다.

| 순서 | 조건 | 잉크 | 잉크병 그림 |
| --- | --- | --- | --- |
| 1 | 눈이 녹색이다 | 숲의 문자 | 잎 |
| 2 | 눈이 파랑이고 귀가 옆으로 길고 뾰족하다 | 별빛 문자 | 별 |
| 3 | 머리가 빨강이나 검정이다. 단, 송곳니가 있으면 건너뛴다 | 불꽃 문자 | 불 |
| 4 | 송곳니가 있다 (돌니 포함) | 짐승 문자 | 송곳니 |
| 5 | 귀가 없다 | 돌의 문자 | 돌멩이 |
| 6 | 위에 하나도 해당하지 않는다 | 공용어 | 빈 동그라미 |

- 예시 1: 엘프 여성, 파란 눈, 금발 → 별빛 문자 → **하트 병 + 별 그림 잉크**.
- 예시 2: 송곳니 있는 수인 남성, 노란 눈, 빨간 머리 → 불꽃은 건너뛰고 짐승 문자 → **네모 병 + 송곳니 그림 잉크**.

### 접객 매뉴얼 (메모)

- 접객 매뉴얼도 약방 주인의 메모 한 장이다. 위쪽에 병 고르는 법이 있고, 나머지에 잉크 여섯 개가 따로따로 흩어져 있다.
- 잉크 규칙을 순서 목록으로 적지 않는다. 잉크마다 자기 조건과 예외만 적는다. 예: 불꽃 문자에는 "머리가 빨강이나 검정", "송곳니 있으면 안 됨. 그건 짐승", "녹색 눈이면 숲, 별빛에 맞으면 별빛이 먼저"가 붙어 있다.
- 그래서 해설자는 종이를 읽어 주는 대신 제조자에게 물어야 한다. "송곳니 있어?", "눈 색은 뭐야?", "머리 빨개?" 같은 문답으로 잉크를 좁힌다.
- 종이 가운데에 "물어볼 것"(눈 색, 귀 모양, 송곳니, 머리 색) 낙서가 있다. 무엇을 물을지만 알려 주고 순서는 알려 주지 않는다.
- 병은 남자 손님 네모, 여자 손님 하트, 어느 쪽도 아닌 분 동그라미로 적는다.
- 판정과 무관한 메모도 섞여 있다. 예: "잉크가 따뜻함", "하트 병은 씻기 귀찮음".

정답은 위 우선순위 표와 같다. 잉크별 메모는 그 표를 풀어 쓴 것이다.

### 레퍼런스

## 엔딩과 결과

손님은 포션을 받자마자 병 → 라벨 → 맛 순서로 반응하고, 그 뒤 결과 팝업에서 무엇을 틀렸는지 보여 준다. 마시는 장면은 따로 그리지 않고 이펙트로 대신한다.

### 반응 순서 (제안)

1. **병을 받는다:** 병이 틀리면 시니컬한 대사로 불만을 드러낸다.
2. **라벨을 본다:** 잉크가 틀리면 "이건 무슨 언어죠?" 하고 되물은 뒤 일단 마신다.
3. **마신다:** 재료 판정에 따라 아래 표의 이펙트와 대사가 나온다.
4. **떠난다:** 손님이 퇴장하고 커튼이 닫힌 뒤 결과 팝업이 뜬다.

| 재료 판정 | 이펙트 | 대사 |
| --- | --- | --- |
| 모두 정답 | 회복 이펙트 | 감사 인사. 잉크만 틀렸다면 "제조술은 괜찮은데 보는 눈이 별로네요"로 대체 |
| 1개 틀림 | 몸 색이 변함 | "맛이 좀 이상한데요?" |
| 2개 이상 틀림 | 연기 폭발 후 슬라임으로 종족 전환 | 슬라임이 된 손님의 항의 |

- 병과 잉크 대사는 재료 반응 앞에 붙는다. 예: 병 틀림 + 재료 1개 틀림 → 불만 대사 → 마신다 → 색 변화와 "맛이 이상해요".
- 슬라임 초상화는 MVP에서 공용 1장으로 시작하고, 여유가 되면 종족별로 나눈다.
- 질병을 틀리면 레시피가 달라져 재료가 틀린다. 그래서 질병은 따로 판정하지 않고 재료 판정에 포함한다.

### 결과 팝업

- 항목별 정답/오답(재료, 병, 잉크), 경과 시간 또는 남은 시간, 점수, 성과 기표를 보여 준다.
- 성과 기표는 마녀 공방 분위기에 맞는 **도장**을 제안한다. 점수 구간별로 도장 3종(예: 명약, 그럭저럭, 슬라임).
- **확인** 버튼을 누르면 팝업만 닫히고 커튼이 닫힌 씬0으로 돌아간다.

| 점수 항목 (초안) | 점수 |
| --- | --- |
| 재료 1개 정답 | 20점씩, 최대 60점 |
| 병 정답 | 20점 |
| 잉크 정답 | 20점 |
| 남은 시간 보너스 | 남은 10초당 5점 |

레시피는 모두 재료 3개이므로 재료 만점은 60점이다.

## 손님 데이터

손님은 미리 정한 인물 22명 가운데 한 명이다. 인물마다 종족, 성별, 귀, 송곳니가 정해져 있고, 헤어 색과 눈 색은 허용 범위 안에서 매 판 바뀐다. 종족은 인간, 엘프, 수인, 골렘 4종이다.

| 종족 | 인물 수 | 성별 | 귀 | 송곳니 | 허용 헤어 색 | 허용 눈 색 |
| --- | --- | --- | --- | --- | --- | --- |
| 인간 | 6 | 남 3, 여 3 | 둥근 귀 | 없음 | 검정, 갈색, 빨강, 금색 | 갈색, 파랑, 녹색 |
| 엘프 | 6 | 남 3, 여 3 | 옆으로 길고 뾰족한 귀 | 없음 | 금색, 은색, 흰색, 검정 | 파랑, 녹색, 보라 |
| 수인 | 6 | 남 3, 여 3 | 동물 귀 | 3명 있음 | 검정, 갈색, 빨강, 금색, 흰색 | 노랑, 주황, 녹색, 파랑 |
| 골렘 | 4 | 없음 | 없음 | 2명 돌니 | 없음 | 노랑, 주황, 파랑 |

- 인물별 이름, 직업, 말투는 MVP 데이터 문서의 인물 표와 인물 목소리 표에 있다.
- **귀는 이름으로 분명히 나눈다.** 수인의 동물 귀도 끝이 뾰족하므로, 별빛 문자는 "옆으로 길고 뾰족한 귀"만 해당한다.
- **골렘에는 녹색 눈을 쓰지 않는다.** 녹색이면 숲의 문자가 먼저 걸려 돌의 문자가 나오지 않기 때문이다.
- **색은 기본색만 쓴다.**

### 초상화 구조

- 초상화는 인물 22명마다 만든다. 얼굴, 체형, 헤어 모양, 귀, 송곳니는 인물에 고정이다.
- 게임용 레이어는 인물당 5장이다. 아래부터 HAIR_BACK, IRIS_SOLID_MASK, BASE, EYE_CLOSED, HAIR_FRONT 순서로 쌓는다. 모두 1024×1536 RGBA이고 중앙 피벗으로 같은 위치에 놓는다.
- 헤어는 회색조로 그리고 엔진에서 헤어 색을 곱한다. 눈 색은 BASE 뒤의 홍채 마스크에 입힌다. 동공과 음영은 BASE에 그려져 있어 눈 색이 바뀌어도 유지된다.
- EYE_CLOSED는 깜빡일 때만 켠다.
- 리소스는 Assets/Arts/Portraits/에, 설명은 저장소 art/portrait-engine-export 브랜치의 Docs/Portraits/README.md에 있다.
- 엔딩용으로 색 변화(틴트)와 슬라임 초상화 1장이 더 필요하다.

### 손님 생성 규칙

1. 정답 잉크를 여섯 가운데서 고르게 먼저 뽑는다. 무작위로 손님을 만들면 숲의 문자가 너무 자주, 짐승 문자가 너무 드물게 나오기 때문이다.
2. 그 정답이 나오는 인물과 헤어·눈 색 조합 가운데 하나를 무작위로 고른다. 병 정답은 인물의 성별로 정해진다.
3. 질병은 따로 무작위로 고른다. 직전 손님과 같은 질병은 피한다.
4. 인물과 색의 허용값은 데이터 파일로 두어 기획자가 직접 고칠 수 있게 한다.

## 확정 사항, 미확정, MVP 테스트

작업을 막지 않도록 기본값을 확정했다. 남은 미확정은 모두 MVP 테스트로 정하며, 그전까지는 기본값으로 작업한다.

### 확정 사항

| 항목 | 확정 내용 |
| --- | --- |
| 대사창 | 출력이 끝난 뒤에도 남아 있음 (다시 읽기 가능) |
| 씬1 → 씬2 | "창고로" 버튼 |
| 제한 시간 | 한 판 전체 180초 하나, 초과 시 손님이 화내며 퇴장 |
| 질병과 포션 | 6개씩, 1:1. 포션마다 재료 3개 |
| 재료 | 6계열 × 3 = 18개 |
| 주머니 | 3칸, 넣은 재료는 꺼낼 수 없음 |
| 손 모델 | MVP는 없음, 집은 재료가 화면 앞에 떠 있음 |
| 성별 단서 | 초상화 외형으로 분명하게 |
| 잉크병 표시 | 그림 6종 (잎, 별, 불, 송곳니, 돌멩이, 빈 동그라미) |
| 해설자 종이 | 메모 7장 (안내표 6 + 접객 매뉴얼 1). 질병 도감 없음 |
| 손님 생성 | 인물 22명, 정답 우선 생성 |
| 손님 대사 | LLM 생성, 실패하면 대체 대사 |
| 성과 기표 | 도장 3종 |
| 손님 표정 | MVP는 변화 없음 |

### 남은 미확정

- [ ] 잡담에도 증상 이펙트를 섞을지
- [ ] 메모의 재료당 메모 수 (지금 6~7개)
- [ ] 잉크별 메모 방식이 20초 안에 풀리는지
- [ ] 손 모델, 종족별 슬라임 (여유가 되면)

### MVP 테스트 항목

- [ ] 처음 하는 두 사람이 3분 안에 한 판을 끝내는가
- [ ] 단계별 시간이 목표(진단 15~20초, 탐색 60초, 처방 20초)에 맞는가
- [ ] 메모 6장에서 15~20초 안에 맞는 장을 찾는가
- [ ] 재료 메모: 쓸모없는 메모가 섞여도 60초 안에 재료 3개를 고르는가
- [ ] 텍스트 이펙트: 증상에만 쓸지, 잡담에도 섞을지
- [ ] 접객 매뉴얼: 문답으로 잉크를 맞히는가, 너무 자주 틀리지 않는가
- [ ] 1인칭 조작: 게임을 잘 안 하는 사람도 바로 익히는가
- [ ] 멀미: 1인칭 이동 속도와 시야각이 편안한가
