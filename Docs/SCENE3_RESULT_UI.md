# Scene 3 제작결과 UI

## 글자 규격

| UI 텍스트 | 글자 크기 | 글자 색상 |
| --- | ---: | --- |
| 상단 `제작결과` | 50px | `#fff7ce` |
| 내용 (항목명, 판정 및 점수) | 50px | `#4d2d13` |
| `총점` 및 점수 | 70px | `#4d2d13` |
| `다음 주문` 버튼 | 60px | `#4d2d13` |

시안에는 `재료 3 / 3` (+60), `물약병 일치` (+20), `잉크 불일치` (+0), `시간 보너스` (+20), `총점 100점`이 예시로 표시되어 있습니다.
