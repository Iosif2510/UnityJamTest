# 게임 변경 사항 안내

팀 저장소 `main`(2026-11-21 "종합 수정") 이후 `feature/online-coop` 브랜치에서 게임이 어떻게 바뀌었는지 알리는 문서입니다. 코드 세부 사항은 빼고, 플레이어가 보고 겪는 것 위주로 적었습니다. GDD(`Docs/GDD.md`)와 데이터 표(`Docs/Ingredients/MVP_Data.md`)와 다른 부분은 **[GDD와 다름]**으로 표시했습니다.

## 한눈에 보기

| 영역 | 무엇이 바뀌었나 |
| --- | --- |
| 플레이 방식 | 같은 자리 종이 메모 방식에 더해 **온라인 2인 협동**과 **혼자하기**가 생김 |
| 씬 구성 | 타이틀 씬(00) 추가, 위층 공방 씬(03) 추가 |
| 창고(씬2) | 지하 창고로 다시 만듦, 조작을 마우스 두 버튼으로 줄임 |
| 접객·처방 | 연출 대폭 추가(커튼, 이름표, 손님 반응, 병 채우기, 마시기, 결과 카드) |
| 손님 | 22명 전원 등장, 셔플 백 순서 |
| 대사 | 사전 생성 대사 표로 교체(실시간 생성 없음) |
| 언어 | 한국어·영어·일본어·중국어(간체·번체) 5개 언어 |
| 옵션 | 소리 4종, 마우스, 흔들림 줄이기, 언어, 제작자 |
| 배포 | 웹(WebGL) 빌드, Unity Play 업로드용 자료 |

규칙 수치(제한 시간 180초, 재료 3종, 점수 배분, 도장 기준)는 바꾸지 않았습니다. 단, 남은 시간 보너스는 실제 게임 값에 맞춰 문서를 고쳤습니다(아래 "데이터").

## 1. 게임 흐름

```
00 타이틀 ─ 혼자하기 ──────────────→ 01 접객(카운터) ⇄ 02 창고 → 01 처방·결과
          └ 함께하기 → 방 만들기/코드 입력 → 역할 정하기 ─┬→ 아래층: 01 접객 ⇄ 02 창고
                                                       └→ 위층: 03 공방(메모 책상)
```

- **[GDD와 다름]** 타이틀 씬이 새로 생겼습니다. 메뉴는 혼자하기 / 함께하기 / 옵션 / 게임끄기(웹에서는 숨김)입니다.
- 접객 화면 왼쪽 위에 **타이틀로** 버튼이 있습니다(온라인 중에도 보임).

## 2. 혼자하기

- 화면 왼쪽 아래 **Tab 메모책** 표시가 있고, Tab을 누르면 해설자 메모 전체를 펼쳐 볼 수 있습니다. 혼자서도 메모를 보며 처방할 수 있습니다.

## 3. 온라인 협동 [GDD와 다름: GDD는 오프라인·같은 자리 전제]

- **두 PC(또는 브라우저)**로 합니다. 한 명이 방을 만들면 6자리 코드가 나오고, 친구가 그 코드를 입력해 들어옵니다. 같은 네트워크에서는 IP 직접 연결도 됩니다(PC판만).
- **게임 안 음성 채팅**이 있습니다(M 키로 마이크 켜고 끄기). 웹판은 "상대가 말하는 중" 표시만 빠집니다.
- **역할은 연결 후에 정합니다.** 두 사람이 표지("가게 잠깐 봐 줘!")를 같이 보고 누가 위층에 갈지 고릅니다. 그다음 "~로 가는 중" 화면을 거쳐 각자 층으로 갑니다.
- **쉬움 모드**(표지 화면에서 켜기): 메모에 노란색(증상 3개)과 초록색(재료 구별점 2개씩) 강조 표시가 생깁니다.
- **아래층 제작자**: 기존과 같이 손님을 맞고 창고에서 재료를 모아 처방합니다. 메모는 볼 수 없습니다.
- **위층 안내자**: 손님을 볼 수 없고, `03_Loft`의 2D 그림 책상에서 메모를 넘겨 보며 말로 안내합니다. 남은 시간은 모래시계로 보이고, 단계가 바뀌면 소리로 알려 줍니다.
- **층 사이 소리**: 위층에는 솥에 재료가 들어가는 소리, 아래층에는 메모 넘기는 소리가 흐릿하게 들립니다.
- **손님마다 역할 교대**: 손님 한 명이 끝날 때마다 두 사람이 위아래 층을 바꿉니다.
- **결말 같이 보기**: 제작자가 포션을 건네면 위층 친구도 카운터로 내려와 병·잉크 고르기, 마시기, 결과까지 같은 장면을 함께 봅니다. 결과를 닫으면 다시 위층으로 돌아갑니다.

## 4. 접객(씬1)과 처방(씬3)

- 손님이 들어오기 전에 **커튼이 열리고**, 손님마다 **이름표**가 내려옵니다. 손님이 도착하면 카메라가 손님 쪽으로 다가갑니다.
- **손님 반응**: 손님을 클릭하면 움찔하고, 세 번 빠르게 찌르면 짜증 냅니다. 남은 시간이 줄면 초조해합니다.
- **대사**: 손님이 말할 때 웅얼거리는 목소리가 납니다. 대사를 클릭하면 2배 빠르게 넘어갑니다.
- **처방 화면**: 병과 잉크 선택지를 알아보기 쉽게 바꿨습니다. 고른 병에 끓인 포션 색이 차오르고, 잉크 라벨이 찍힙니다.
- **마시기**: 손님이 포션을 마시고 결과에 따라 변합니다. 다 나으면 바로 웃습니다. 재료가 둘만 맞으면 색이 이상해지고, 그보다 적으면 슬라임이 됩니다.
- **시간 초과** 장면을 따로 넣었습니다.
- **결과 카드**: 재료·병·잉크·시간 보너스 점수와 도장이 한 장에 나옵니다. 도장 그림도 언어별로 있습니다.
- 손님은 **22명 전원**이 등장하고, **셔플 백**(모두 한 번씩 나온 뒤 다시 섞임)으로 특정 손님이 몰리지 않습니다. 초상화 17종에 숨쉬기 같은 대기 동작을 넣었습니다.

## 5. 창고(씬2) [GDD와 다름: 분위기와 조작]

- **지하 창고**로 다시 만들었습니다(창문 없음). 긴 홀 구조이고, 선반·벽난로·책장 등 소품을 채웠습니다.
- **분위기**: 위치에 따라 들리는 환경음(불, 솥, 등불, 물방울, 위층 발소리), 떠다니는 먼지, 바닥 안개, 솥 색으로 물드는 빛, 움직일 때 흔들리는 불꽃.
- **조작**(마우스 두 버튼):
  - 왼쪽 클릭: 집기, 솥에 넣기
  - 왼쪽 드래그: 들고 있는 재료 돌려 보기
  - 오른쪽 클릭: 제자리에 두기
- 들고 있는 재료는 화면 가운데 크게 보입니다. 재료 이름은 집기 전까지 **"이름 모를 버섯", "이름 모를 뿌리"**처럼 종류만 보입니다.
- 넣은 재료는 화면 아래 칸에 하나씩 채워집니다(3칸).

## 6. 메모(해설자 자료)

- 카운터 매뉴얼을 **후보 E**로 교체하고 오타를 고쳤습니다.
- 게임 안 메모는 장마다 다른 **누런 양피지 질감**에 세피아 잉크로 바꿨습니다. 인쇄용 흰 원본(`Docs/PotionMemos`)은 그대로 둡니다.
- 그림과 글자를 분리해서, 다른 언어에서는 같은 그림 위에 번역 글자를 얹습니다. 한국어는 손글씨 원본 그대로입니다.

## 7. 데이터·대사

- 재료 이름과 특징 문구를 11-19 개정 메모와 `MVP_Data.md`에 맞췄습니다(재료 id와 모델은 그대로).
- **남은 시간 보너스**: 문서는 "10초마다 5점"이었지만 게임은 처음부터 "남은 초 × 0.1점(소수점 버림)"이었습니다. 문서를 게임에 맞췄습니다.
- **[GDD와 다름]** 손님 대사는 실시간 생성 대신 **미리 만든 대사 표**(GPT로 132개 생성, `Assets/GameData/DialogueTable.json`)를 씁니다. 표에 없거나 틀린 항목은 기본 대사로 대체됩니다.

## 8. 다국어

- 게임 언어 하나로 UI·손님 대사·메모·로고·결과 도장이 모두 바뀝니다. 언어는 옵션에서 고르고, 처음에는 컴퓨터 언어를 따릅니다.
- 번역은 **AI 초안**입니다. 원어민 검수가 필요합니다.

## 9. 옵션과 제작자

- 옵션 탭:
  - 소리: 전체, 음악, 효과음, 손님 목소리
  - 조작: 마우스 감도, 위아래 반전
  - 화면: 전체 화면, 화면 흔들림 줄이기(멀미 방지)
  - 언어
  - 제작자: 기획 JiuPark, 프로그래머 Iosif2510, 3D 아티스트 Synnn, 2D 아티스트 JebeenSon, 후원(유니티, 한국게임산업협회, OpenAI, Meshy.ai), Unity AI Game Jam (2026). 명단은 `Assets/Resources/credits.json`에서 고칩니다.

## 10. 소리와 음악

- 효과음 14종을 ElevenLabs 녹음으로 바꾸고 음량을 맞췄습니다.
- 음악: 타이틀 곡, 위층 공방 곡, **남은 30초 이하에서 나오는 급한 곡**(Suno).
- 중요한 순간마다 효과음과 화면 반응을 넣었습니다(솥 불꽃이 튀기, 재료가 들어갈 때 화면이 살짝 밀림 등). 화면 흔들림은 옵션에서 끌 수 있습니다.

## 11. 배포

- **웹(WebGL) 빌드**를 만들었고 Unity Play 업로드용 자료를 준비했습니다(`Docs/UnityPlay`: 썸네일, 영어 플레이 영상 56초). 페이지 문구는 `Docs/UNITY_PLAY_PAGE.md`에 있습니다.
- 웹판에서 달라지는 점:
  - 게임끄기와 IP 직접 연결이 없습니다.
  - 솥의 VFX 효과 하나가 빠집니다(브라우저가 지원하지 않음).
  - 창고에 들어갈 때 로딩이 10~15초 걸립니다.
  - 방 만들기가 15~20초 걸릴 수 있습니다(가까운 서버를 찾는 과정이 느림).
- 빌드 방법과 프로그래머 확인 목록은 `Docs/WEB_BUILD.md`에 있습니다.

- 손님 대사 132개와 영어·일본어·중국어 문구는 AI로 만든 것입니다.
