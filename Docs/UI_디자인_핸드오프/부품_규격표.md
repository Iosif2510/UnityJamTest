# 부품 규격표

`확정_시안_B안/`의 화면을 낱개 부품으로 나눈 목록이다. 2026-11-23 기준.

크기는 모두 1920×1080 화면 기준 픽셀이다. 와이어프레임에서 잰 값이라 그림에 맞게 조금씩 바꿔도 된다. 바꾸면 이 표도 같이 고친다.

## 공통 규칙

- 납품 규격은 README 6장을 따른다. PNG, 투명 배경, 가로세로 4의 배수, 둘레 투명 여백 2픽셀 이상, 글자 없음.
- 9분할 부품은 파일 이름 끝에 모서리 크기를 붙인다. 예: `LOFT_Felt_9slice_64.png`는 모서리가 64픽셀이다.
- 가로로만 늘어나는 부품은 3분할로 그리고 `_3slice_<모서리>`를 붙인다.
- 상태가 여러 개인 부품은 상태마다 파일 하나다. 크기와 기준점이 모두 같아야 한다.
- 접두어: 위층 공방 전용은 `LOFT_`, 온라인 화면 전용은 `NET_`, 여러 화면에서 같이 쓰면 `UI_`.

## 4. 시안과 다르게 해도 되는 것

- 시안은 이미지 생성으로 뽑은 방향 시안이다. 장식의 세부(잎 무늬, 나뭇결 방향, 놋쇠 모양)는 디자이너가 다시 잡는다.
- 색감, 선 없이 면으로 칠하는 방식, 거친 붓결, 형광 없는 하이라이트는 지킨다.
- 메모 종이 안의 그림과 표지 메모는 자리 채우기다. 실제 메모를 쓴다.
