# 부품 규격표

`부품_PNG/`에 있는 부품 49개의 목록이다. 2026-11-23 기준. 기존 게임 UI에 맞춘 판(v2)이다.

크기는 모두 1920×1080 화면 기준 픽셀이다. 이 부품으로 조립한 화면 8장은 `조립_시안/`에 있다.

## 공통 규칙

- PNG, 투명 배경, 가로세로 4의 배수, 둘레 투명 여백 2픽셀 이상, 글자 없음. 글자는 코드로 얹는다 (메이플스토리 Bold).
- 상태가 여러 개인 부품은 상태마다 파일 하나다. 크기와 기준점이 모두 같다.
- 9분할·3분할 부품의 테두리는 `부품_PNG/_borders.json`에 `[왼쪽, 위, 오른쪽, 아래]`로 적혀 있다. PNG 가장자리부터 잰 값이고 투명 여백 2픽셀을 포함한다. Unity Sprite Editor의 Border(L, T, R, B)에 그대로 넣는다.
- 3분할 부품(가로로만 늘어남)은 원본 높이 그대로 쓴다.
- 접두어: 여러 화면 공용은 `UI_`, 위층 공방 전용은 `LOFT_`, 온라인 화면 전용은 `NET_`, 배경은 `BG_`.
- 메이플스토리 폰트에는 ✓, ▸ 같은 기호가 없다. 화면 글자에 쓰지 않는다.

## 6. 만든 방법과 검사

- 기존 에셋이 있는 부품은 그 에셋에서 만들고, 나머지는 기존 장면과 에셋을 기준 그림으로 이미지 생성 후 다듬었다.
- 모든 부품은 검사 스크립트로 확인했다: 크기, 4의 배수, 투명 여백, 배경색 잔여, 9분할 테두리가 쓰는 크기보다 작은지, 변과 가운데를 늘렸을 때 얼룩이 생기지 않는지.
- 9분할 부품은 늘려도 깨지지 않게 변과 가운데를 고르게 만들었다. 그래서 원본 에셋보다 가운데 질감이 조금 단순하다.
