# Scene 1 분리 파츠 · 컬러 텍스처 · 노말맵

전체 구도의 배경을 레이어로 사용할 수 있도록 정리한 아트 에셋입니다.

## 구성

| 파츠 | 포함 요소 |
| --- | --- |
| Background | 창구 뒤 배경과 장식 |
| Wall | 나무 프레임, 양옆 벽, 덩굴과 벽 소품 |
| Curtains_Open | 열린 커튼과 커튼봉 |
| Curtains_Closed | 닫힌 커튼과 커튼봉, 크기/위치 보정 완료 |
| Table | 테이블 상판과 앞판, 위쪽 소품과 앞판 장식 전체 |

BaseColor/의 5개 PNG가 컬러 텍스처이자 분리된 이미지 파츠입니다. 같은 이미지를 중복 저장하지 않았습니다.
Normals/에는 각 PNG에 대응하는 OpenGL(+Y) 노말맵 5개가 있습니다.

## 배치와 커튼 전환

모든 파일은 투명도를 포함한 1672 × 941 공통 캔버스입니다. 원점과 스케일을 동일하게 놓고 Background → Wall → 커튼 → Table 순서로 겹칩니다. 커튼은 Open 또는 Closed 중 하나만 표시합니다.

열린 커튼은 원본 크기 그대로 보존했습니다. 닫힌 커튼은 미리보기에서 봉에 맞춘 크기와 위치를 컬러 PNG와 노말 PNG 모두에 반영했습니다. 따라서 이 폴더의 닫힌 커튼에는 별도의 CSS/Transform 보정을 다시 적용하지 않습니다. 닫힌 노말맵의 원본 1픽셀 너비 차이도 공통 캔버스로 정규화했습니다.

## Unity 임포트

컬러는 Sprite(2D and UI), sRGB, Full Rect, 100 PPU, 알파 투명으로 설정했습니다. 각 컬러 스프라이트의 Secondary Textures에 대응하는 노말맵을 _NormalMap 이름으로 연결했습니다. 노말 텍스처는 Normal Map/Linear로 설정했습니다. 모든 파일에 고유 GUID의 .meta가 포함되어 있습니다.

실제 씬 배치나 머티리얼 변경은 포함하지 않습니다. Sprite-Lit 계열 머티리얼과 프로젝트의 2D 조명 설정에서 사용하세요.

## 제작과 확인 범위

분리 이미지는 기존 그림을 참고해 가려진 부분을 복원한 결과입니다. 컬러 텍스처에는 기존 그림의 명암이 포함되어 있습니다. 노말맵은 2D 그림에서 추정한 이미지 생성 결과로, 실제 3D 메시에서 베이크한 측정값은 아니며 일부 세부 윤곽과 차이가 있습니다.

파일 크기, PNG 알파 형식, GUID 중복, 컬러-노말 연결, Git LFS 추적을 확인했습니다. Unity Editor에서의 렌더링 검증은 수행하지 않았습니다. manifest.json에 각 파일의 SHA-256과 닫힌 커튼 보정 이력을 기록했습니다.
